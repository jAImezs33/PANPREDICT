# Próximos pasos

## Base de esta propuesta

- Demo local y CSV sintético.
- Validación explícita, ceros conservados y huecos señalados.
- Referencia semanal y AutoARIMA opcional.
- Evaluación temporal y pruebas de regresión, interfaz y CLI.
- Licencia y guía de contribución.

## Siguiente ciclo

1. Conseguir voluntariamente 3–5 personas que prueben la instalación.
2. Resolver fallos reproducibles con datos sintéticos.
3. Acordar un primer piloto siguiendo PILOT.md.
4. Comparar métodos con varias ventanas temporales.
5. Registrar uso recurrente real, sin contar pruebas propias como adopción.

## Trabajo posterior

- Evaluación temporal con múltiples ventanas.
- Casos de productos nuevos, descatalogados y roturas de stock.
- Más formatos de TPV y pruebas de accesibilidad.
- Dependencias bloqueadas tras comprobar combinaciones soportadas.
- Si se autoriza, comprobación de integraciones con destinos de prueba.

No se garantiza aceptación en programas externos. Los umbrales de programas
no deben orientar la creación de actividad artificial.
